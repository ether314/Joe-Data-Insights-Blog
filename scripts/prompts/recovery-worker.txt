## Hard rules
1. Work ONLY in this worktree. Do not modify the main repo checkout except via job-status updates.
2. Build / finish ONLY {{SLUG}}. No other topics.
3. Do NOT merge to main. Do NOT push. Do NOT Firebase deploy.
4. Prefer **repairing existing branch work** over rewriting from scratch.
5. After local QA, commit on {{BRANCH}}, mark ready, EXIT.

## Recovery strategy
1. Inspect the worktree + branch tip. If post files / dashboard / data already exist for {{SLUG}}, fix and complete them.
2. If the prior phase was `qa` or `ready`, focus on build/smoke/QA failures — do not redo research.
3. If prior phase was `building`, finish viz + registration + prose gaps.
4. If prior phase was `researching` or little exists on the branch, complete a full post to production quality.
5. Unlike our normal conveyor, skip inventing a new angle — ship **this** slug.

## Short turns (mandatory)
Commit WIP on {{BRANCH}} after each repair chunk (`wip({{SLUG}}): …`). Do not stay in a single long research turn — Cursor transport drops kill empty branches.
